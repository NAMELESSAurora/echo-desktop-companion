# 前端测试台

本轮目标是在现有后端上验证文本、画面、音频和打断。界面不调用真实供应商，不使用浏览器朗读替代后端音频，也不采集麦克风。

## 设计

主体是桌面伙伴的交互测试。采用雾蓝背景、白色对话区和安静的状态侧栏；颜色和字体在 `frontend/src/tokens.css` 维护。显示字体使用 Segoe UI Variable Display／微软雅黑，正文使用 Segoe UI／微软雅黑，事件数据用 Cascadia Code／Consolas。

布局是左侧会话、中间对话、右侧画面与声音。声音区域的波形取自实际 Web Audio 分析器，没有播放时只显示平线。首字、首段音频和生成耗时来自后端事件，不填虚构指标。窄屏折为单列，系统减少动态效果时禁用装饰动画。

## 模块

- api.ts：同源连接、HTTP 错误与支持分块 UTF-8／多行 data 的 SSE 解析。
- turns.ts：轮次调度、串行 POST 创建、迟到结果丢弃、服务端取消。
- audio.ts：PCM16 little-endian 解码、按采样率调度、音量与清空队列。
- screen.ts：浏览器窗口流、合成画面、权限队列、按需截图与撤权。
- main.ts：界面绑定、消息与事件记录、播放器状态和会话切换。
- avatar-state.ts：独立的形象状态与音量包络；不依赖渲染器。
- avatar.ts / avatar-drivers.ts / vrm-driver.ts：Three.js 舞台、内置形象及本地 VRM。
- vrm-file.ts：本地模型体积、格式和资源边界验证。

所有用户文本通过 textContent 渲染。图片只在发送时临时转成 JPEG；前端不把截图写入 localStorage 或会话历史。预览流会在停止共享、原生轨道 ended、新会话和页面离开时关闭。

## 取消与竞争

本地停止先于网络取消。即使旧 POST 尚未返回，轮次也先标记失效；返回 turn_id 后再取消，且不消费其事件。创建请求串行，事件流独立运行，防止旧 POST 晚到后在后端反过来打断新消息。

屏幕授权写入按队列执行。开启授权未返回时点击停止，前端立即丢弃来源，随后完成撤权；旧开启结果不能恢复预览。媒体选择器晚返回的流会立即关闭。

后端 generation completed 与浏览器播放结束分开显示。收到 audio.clear、失败、打断或开始新轮时，立即停止所有已调度 AudioBufferSourceNode；按 turn_id 过滤旧音频。浏览器自动播放策略由首次发送／声音开关的用户手势解锁。

## 验证范围

前端单元测试验证 SSE 分块、音频解码与停止、轮次竞争、共享授权竞争以及媒体轨道结束。后端测试覆盖模拟 cookie、同源限定和 live 拒绝。

浏览器实际验证覆盖真实本地 HTTP/SSE、文字发送、合成画面发送、PCM 播放、重播、静音、打断及共享停止。系统原生窗口选择器由用户最终选择具体窗口；自动化没有替用户授权读取整个桌面。媒体流结束和选择器晚返回分支由合成对象测试覆盖。
